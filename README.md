# Métodos de ordenamiento externo en Python

Ejercicios de la materia de Estructura de Datos sobre ordenamiento externo trabajando con archivos de texto.

## Archivos

- `intercalacion.py`: junta los tickets de venta de dos sucursales que ya vienen ordenados en un solo archivo.
- `mezcla_directa.py`: ordena un archivo de inventario desordenado por código usando dos archivos auxiliares.
- `mezcla_equilibrada.py`: ordena un archivo de reportes de soporte aprovechando los tramos que ya vienen ordenados con cuatro archivos auxiliares.

## Cómo correrlos

Solo necesitas Python 3, no usan librerías externas. Cada código genera sus propios archivos `.txt` de prueba al ejecutarse:

```bash
python intercalacion.py
python mezcla_directa.py
python mezcla_equilibrada.py
```
